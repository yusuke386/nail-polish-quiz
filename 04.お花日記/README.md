# お花日記

趣味で撮ったお花を、1日1つの記録（写真3枚まで・メモ・撮影場所）として残す日記。研修クイズとは別物で、合言葉ロックはなし。

## 画面

- **月**（最初の画面）… カレンダーの各日に、その日の写真を1枚表示。日付をタップすると、カレンダーの下にその日の写真とメモが出る（最初は今日）。記録のない日は「この日のお花を記録する」ボタンが出る。その下の「最近のお花」には最近の写真が並び、タップするとその日に移動する
- **週** … 月カレンダー左の「週」をタップすると切り替わる。その週の写真をすべて表示
- **地図** … 全期間の写真を、撮影場所に丸い写真のピンで表示。ピンをタップすると日付とメモが出て、「この日の記録を見る」で詳細へ

右下の「＋」で今日の記録を書く（すでにあれば編集になる）。

記録画面でメモや花の名前の欄をタップすると「書くモード」になり、打っている欄だけが表示される（写真や裏の画面を描かないので、iPhoneでも文字入力が軽い）。上の「完了」で元の記録画面に戻り、「保存する」を押す。

## 花言葉

記録画面で、写真ごとに「花の名前」を入れると花言葉が自動で入る。

- ひらがなで途中まで打つと候補が出る（例：「ちゅー」→ チューリップ、チューリップ（赤）…）。「桜」「さくら」のような打ち方でも見つかる
- 自動で入った花言葉は自由に書き換えられる。一覧にない花は、名前と花言葉を自分で入力する
- 花言葉は、カレンダー下のその日のカード・週表示・詳細画面・地図のピンの吹き出しに出る
- 花言葉の一覧は `hanakotoba.js`（約170種類）。花言葉は出典によって違いがあるので、よく知られているものを2〜3個ずつ載せている。花を足すときは同じ形で1行追加する

## 撮影場所の記録

1. 写真に位置情報（EXIF）が入っていればそれを使う（入力画面で「📍写真」と表示）
2. 入っていない場合、**今日の記録のときだけ**スマホの現在地を使う（「📍現在地」）。過去の日の記録では現在地は使わない（家で後から書いたときに自宅の位置が入らないようにするため）

写真に位置情報が付かない場合は、iPhoneの設定（プライバシー → 位置情報サービス → カメラ）やアップロード時の設定を確認。

## データの保存先

- 写真・メモ・撮影場所は **このスマホのこのブラウザの中だけ**（IndexedDB）に保存。どこにも送信しない
- 地図の表示にだけ、インターネット接続が必要（地図画像: OpenStreetMap／表示ライブラリ: Leaflet を CDN から読み込み）

### 使うときの注意（iPhone）

- **Safari で開いて「共有」→「ホーム画面に追加」し、最初からホーム画面のアイコンから使う**のがおすすめ。Safari の普段のタブで使うと、しばらく開かない日が続いたときにデータが消されることがある
- Safari のタブとホーム画面のアイコンは、保存場所が別。途中で切り替えると記録が見えなくなるので、どちらか一方で使う
- プライベートブラウズでは使えない

## アイコン

- `apple-touch-icon.png`（180×180）… iPhoneで「ホーム画面に追加」したときのアイコン（手帳に貼ったお花の写真）
- `icon.svg` … ブラウザのタブに出るアイコン（同じ絵）

## バックアップ

右上の歯車ボタン →「バックアップを保存する」で、写真込みの全記録をファイル（JSON）に保存できる。機種変更のときは、新しいスマホで「バックアップを読み込む」を選ぶ（すでに記録がある日はそのまま残り、ない日だけ追加される）。ときどき保存しておくと安心。
