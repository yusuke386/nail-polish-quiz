# お花日記

見つけたお花や飾ったお花を、日付・写真・メモで記録する個人用の日記。研修クイズとは違い、4択などの出題機能はありません。

## 使い方

`index.html` をブラウザで開くだけ（ダブルクリック可）。スマホでは AirDrop などで送って「ファイル」アプリから開く、または GitHub Pages のURL（`04.お花日記/`）を開いてホーム画面に追加する。

- 右下の「＋」から記録を追加（日付・タイトル・写真・メモ）
- 写真は複数枚追加可。保存前に自動で縮小・圧縮される
- 一覧は日付の新しい順に表示。カードの「編集」「削除」で変更可能
- データは**この端末のこのブラウザの中だけ**に保存される（localStorage）。他の端末やブラウザとは共有されない

## バックアップについて

ブラウザのデータを消す・機種変更する・別のブラウザで開く、などをすると記録は引き継がれません。

- 「書き出し（バックアップ）」でJSONファイルとして保存できる
- 「読み込み」で書き出したJSONファイルを取り込める（既存データに追記されるので、機種変更時は新しい端末で読み込めばOK）

## 合言葉について

他のクイズと違い、合言葉によるロックは設けていません（個人利用のため）。ただしリポジトリが公開設定の場合、ページ自体（プログラム部分）は誰でも閲覧できます。日記の中身（写真・メモ）はブラウザ内にしか保存されないためページには含まれませんが、機微な内容の記録には注意してください。
