# FRANGES DIVINES 商品名クイズ

新人バイト研修用。口紅写真の右上に表示されるコード（例:A6）を見て、ルージュ ウーフォリ ドゥ ラ ソワ の商品名（漢字＋ローマ字）を4択で当てるテスト。

## 使い方

`index.html` をブラウザで開くだけ（ダブルクリック可）。スマホでは AirDrop などで送って「ファイル」アプリから開く。

- 合言葉を入力（マニキュアクイズと共通）
- 出題数を 10 / 20 / 全部 から選んで「はじめる」
- 写真タップで拡大
- 終了後、間違えた商品を復習リストで確認 → 「間違えた問題だけ復習」で再挑戦
- 自己ベストは端末内（localStorage）に保存
- スタート画面の「← 別のクイズを選ぶ」から、一つ上の階層にある選択画面（`../index.html`）経由でマニキュアクイズにも切り替えられる

## データ

- 対象: ルージュ ウーフォリ ドゥ ラ ソワ 系 40点（A1〜A10 / B1〜B10 / C1〜C10 / D1〜D10）
- 取得元: https://f-divines.com/collections/lipstick （2026-09 時点、全46商品中コード体系に乗る40点を採用）
- 除外したもの: ギフトカード・eギフト、セット商品（K2＆Causette.Joliセット）、コード体系に乗らない数量限定品（K2単品・KOCHI・HAE）
- 画像は f-divines.com の CDN を直接参照。**ネット接続が必要**。ダウンロードはしていない。

### データ更新のしかた

`index.html` 内の `RAW` 配列を編集する。1行 = `["コード", "漢字名", "ローマ字名", "シリーズ番号(Ⅰ/Ⅱ/Ⅲ)", "画像ファイル名"]`。
画像ファイル名は商品ページ画像URLの `cdn/shop/files/` 以降（クエリパラメータは省略可）。
