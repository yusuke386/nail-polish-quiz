# パーソナルカラー診断トレーニング

新人バイト研修用。一般的な4シーズン（春夏秋冬）パーソナルカラー診断法の知識と、接客での提案力を鍛える練習アプリ。

## 使い方

`index.html` をブラウザで開くだけ（ダブルクリック可）。スマホでは AirDrop などで送って「ファイル」アプリから開く。

- 合言葉を入力（マニキュアクイズ・口紅クイズと共通）
- モードを選ぶ
  - **知識クイズ**：4シーズン診断法の基礎知識（イエベ／ブルベの判断基準、各タイプの特徴、似合う色など）を4択で確認。レベルを「初級/中級/上級」から選べ、中級・上級には一般色彩理論（色彩検定2級相当：PCCSトーン、配色技法、マンセル表色系など）の問題も混ぜてある。10問/20問/全部から出題数を選べる。
  - **接客シミュレーション**：架空の来店客（写真＋肌・髪・瞳の色スワッチ＋特徴の説明文）を見て、①似合うシーズン、②おすすめの口紅の色、の両方を答える。両方正解して初めて正解になる。全16件を毎回通しで出題。
- 回答後は正解の理由（診断根拠・おすすめ理由）と、間違えた場合はどこが違うのかの解説が表示される
- 終了後、間違えた問題だけ復習できる。自己ベストは端末内（localStorage）に保存
- スタート画面の「← 別のクイズを選ぶ」から選択画面（`../index.html`）経由で他のクイズにも切り替えられる

## データ

このアプリには3種類のデータがあり、すべて `index.html` 内に直接埋め込まれている。

### 1. 知識クイズの問題（`KNOWLEDGE_BEGINNER` / `KNOWLEDGE_INTERMEDIATE` / `KNOWLEDGE_ADVANCED`）

一般的に知られている4シーズン診断法の基礎知識、および色彩検定2級相当の一般色彩理論をもとに作成した問題集（初級28問・中級27問・上級28問）。特定サイトの転載ではない。

- 1行 = `[問題文, 選択肢4つの配列, 正解のindex, 解説文]`
- 正解は選択肢の先頭（index 0）に書いておけば、出題時に自動でシャッフルされる
- レベルごとの配列は `QUESTIONS_BY_LEVEL` にまとめられ、スタート画面の「レベル」セグでどれを出題するか選ぶ

### 2. 口紅のシーズン分類（`RAW_LIPSTICK`）

`02.口紅クイズ` で扱っている FRANGES DIVINES「Rouge Euphorie de la soie」口紅40点について、**ブランド公式のカラーチャート**（夏/春/秋/冬 × イエロー/ブルー/ニュートラルの一覧表）に基づいて分類したデータ。コードの頭文字がそのままシーズンに対応する（A=夏、B=春、C=秋、D=冬）。各シーズン内の並び順（1〜4:イエローベース／5〜8:ブルーベース／9〜10:ニュートラル）も公式チャート準拠。

40点全てが公式チャートに明記されているため、全件 `typical:true`（曖昧な判定はない）。代表色hexのみ、実際の商品写真からのRGBサンプリングによる補助データ（色チップ表示用）。

- 1行 = `[コード, 漢字名, ローマ字名, シーズン("spring"|"summer"|"autumn"|"winter"), 代表色hex, 典型例か(true/false), 分類理由]`
- シーズン集計：春10点・夏10点・秋10点・冬10点（均等）

### 3. 接客シミュレーションの来店客データ（`PERSONA_RAW`）

実在の人物ではなく、各シーズン4件ずつ・計16件を教育目的で作成した架空の設定。診断根拠は色スワッチ（肌・髪・瞳）と文章で表現し、写真は「雰囲気作り」のために追加している（下記「来店客の写真について」参照）。

- 1行 = `[肌の色hex, 髪の色hex, 瞳の色hex, 特徴の説明文, 正解シーズン, 診断理由, おすすめ商品コード, 写真ファイル名]`
- `おすすめ商品コード` は `RAW_LIPSTICK` の中で `typical:true` かつ同じシーズンのものを指定する
- `写真ファイル名` は下記Supabase Storageのバケット内のファイル名（`PHOTO_BASE` と連結してURLになる）

### データ更新のしかた

上記いずれの配列も `index.html` 内の該当箇所を直接編集する。`RAW_LIPSTICK` の分類やコメントを見直したい場合は、`02.口紅クイズ` の商品写真（`fdswatch_*` / `fdlip_whole*`）を見比べながら判断すると良い。

## 来店客の写真について

接客シミュレーションの各ペルソナには、雰囲気作りのための写真を1枚ずつ付けている（診断の正解・不正解の判定には一切使っていない。判定は色スワッチと `season`/`recommended` の値のみで行う）。

- **出典**: [ぱくたそ (pakutaso.com)](https://www.pakutaso.com/) のフリー素材（商用利用可、モデルリリース取得済みのものを含む）
- **用途**: 実在の人物ではなく、教育目的で作成した架空の来店客イメージとしてのみ使用。特定の商品・企業のイメージキャラクターとしての利用や、なりすまし目的の利用ではない
- **保存先**: pakutasoの画像は直リンク（ホットリンク）ができないため、Supabase Storageの公開バケットに保存して読み込んでいる
  - バケット: `personal_color_free-picture`（Public）
  - ファイル名規則: `persona-<season>-<1〜4>.jpg`（例: `persona-spring-1.jpg`）
  - `index.html` 内の `PHOTO_BASE` 定数がこのバケットの公開URLのベースになっている
- 写真が読み込めない場合（バケット削除・URL変更など）は自動的に写真部分を非表示にし、色スワッチと説明文だけで出題を継続する（`onerror` フォールバック実装済み）

## 合言葉ロックについて

合言葉のハッシュ（`LOCK_HASH`）はマニキュアクイズ・口紅クイズと同じ値を使っている（意図的な仕様。バグではない）。localStorageのキーはこのアプリ専用の `pc_quiz_` プレフィックスにしてあり、自己ベストは他のクイズと混ざらない。
